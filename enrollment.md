### 1.1. Mục đích

Tài liệu này hướng dẫn user các bước chi tiết sử dụng tính năng đăng ký học của hệ thống SAPP Portal.

### 1.2. Đối tượng & phạm vi áp dụng

| Vai trò  | Mô tả                                      | Phạm vi thao tác                                                       |
| -------- | ------------------------------------------ | ---------------------------------------------------------------------- |
| Học viên | Người học đã đăng nhập vào hệ thống Portal | Đăng ký học, xem/sửa/xóa đăng ký cá nhân, xem danh sách khóa học gợi ý |

<summary>2. Xem danh sách đăng ký cá nhân</summary>

<figure><img src=".gitbook/assets/image (175).png" alt=""><figcaption></figcaption></figure>

| Tên trường thông tin | Mô tả                                                                                                                              |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| #                    | Số thứ tự đăng ký                                                                                                                  |
| Program              | Chương trình học                                                                                                                   |
| Subject              | Môn học                                                                                                                            |
| Session Info         | Thông tin ca học                                                                                                                   |
| Registration Period  | Tên đợt đăng ký                                                                                                                    |
| Status               | Trạng thái mở lớp. Có 3 trạng thái: Opening Soon (lớp chờ mở), Class Opened (đã mở lớp), Not Eligible Open (không đủ điều kiện mở) |
| Class Code           | Mã lớp học đã mở                                                                                                                   |

{% hint style="info" %}
Người dùng có thể **tìm kiếm** đăng ký của mình qua bộ lọc **Status** (Trạng thái mở lớp), **Subject** (Môn học), **Registration Period** (Đợt đăng ký).

## III. Lưu Ý & Quy Tắc Nghiệp Vụ

{% hint style="warning" %}
### Lưu ý quan trọng

1. Hệ thống chỉ hiển thị các môn học mà học viên đã đăng ký với TVTS.
2. Chỉ có thể **sửa** hoặc **xóa** lượt đăng ký khi Status (Trạng thái mở lớp) = Opening Soon.
{% endhint %}

{% hint style="info" %}
### Mẹo sử dụng

1. Dùng bộ lọc **Status / Subject / Registration Period** tại tab My Registrations để nhanh chóng tìm đúng lượt đăng ký.
2. Tại tab Recommended Courses, có thể đăng ký thêm lớp cùng môn nhưng khác ca học / cơ sở học.
{% endhint %}

## IV. Các Lỗi Thường Gặp & Cách Xử Lý

| Lỗi / Tình huống               | Nguyên nhân                                                                 | Cách xử lý                                                 |
| ------------------------------ | --------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Không thấy môn học cần đăng ký | Học viên chưa đăng ký môn học đó với TVTS                                   | Liên hệ TVTS để được đăng ký môn học trước khi đăng ký lớp |
| Không thấy icon Edit / Delete  | Status lớp không còn là Opening Soon (đã mở lớp hoặc không đủ điều kiện mở) | Chỉ có thể sửa/xóa khi lớp ở trạng thái Opening Soon       |
| Không tìm thấy dữ liệu         | Sai bộ lọc                                                                  | Kiểm tra lại điều kiện tìm kiếm và thử lại                 |
